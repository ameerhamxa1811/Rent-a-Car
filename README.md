# Rent-a-Car

A powerful and intuitive car rental application built using **Flutter**, **Firebase**, **BLoC**, and **Clean Architecture**. Designed with scalability in mind, it integrates **OpenStreetMap** to enhance location services, making it easy for users to find, book, and manage rental vehicles.

---

## 🧾 Overview

The Rent-a-Car app offers a complete solution for booking and managing rental vehicles. With modular architecture and clean separation of concerns, it ensures a maintainable codebase and high performance. The app is easily customizable for other rental scenarios like bikes, tools, or properties.

---

## ✨ Features

* 🚗 Browse available vehicles by type, location, and availability
* 📍 Real-time location using **OpenStreetMap**
* 🔒 Firebase Authentication
* ☁️ Firestore integration for real-time data handling
* 🧭 Google and OpenStreetMap navigation integration
* 📆 Booking and reservation management
* 📊 Booking history and status tracking
* 🛠 Built with BLoC for structured and reactive state management
* 💡 Clean, modern UI/UX

## 🧰 Technologies Used

* **Flutter** – Cross-platform UI toolkit
* **Dart** – Application language
* **Firebase Auth & Firestore** – Backend services
* **BLoC** – Business logic separation and reactive state
* **OpenStreetMap** – Location display and routing
* **Geolocator/OSM Flutter Plugins** – Location services

---

## 🧱 Architecture

Follows **Clean Architecture** principles:

* **Presentation Layer** – UI, screens, and BLoC logic
* **Domain Layer** – Entities, repositories, use cases
* **Data Layer** – API and Firebase implementations

This structure makes the app scalable, testable, and easier to maintain.
